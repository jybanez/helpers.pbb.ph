Application contract

const picker = createRepositoryPicker({
  context: projectId, folderId: null,
  loadFolder: ({folderId, signal}) => loadProjectFolder(folderId, signal),
  onUpload: (files, {folderId, signal}) => uploadFiles(files, folderId, signal)
});
const attachments = await picker.pick();
// Composer options:
attachmentAdapter: {mode: 'custom', open: ({signal}) => picker.pick({signal})},
onAttachmentsSelected: (records, {kind, source}) => addToDraft(records)

Preload factories before user interaction. The picker mounts and sets busy state before calling the loader. Return folder, breadcrumbs, folders, files and permissions; canonical file records need stable repository-wide ids and names. Folder activation navigates; only files can be selected.

Behavior checklist

  • At 375 x 667, choose Six files: the list fits without scrolling. Choose Long folder: scroll the modal body while the header and footer stay fixed.
  • Select the brief, visit Design, then select a design file: both remain selected. Navigate back using the breadcrumbs to see the selected row.
  • Use the header Upload files icon to upload a file in Design. A success toast confirms the upload without adding a body row. The returned record becomes available for explicit selection.
  • Choose slow loading and cancel immediately: late results must not reopen the dialog.
  • Read failures offer Reload folder; upload failures never replay the mutation.
  • Permissions hide or disable Upload; server authorization is always required.
  • Folders appear first; file-type icons come from Helper. Click a file row or use Tab, Enter and Space to toggle its highlight. In the ready state, Escape clears selection across all folders; press it again to dismiss. Cancel and the close button dismiss directly. Resize to mobile width.
