Timeline Demo

Build a chronological event history, then add date groups, actions, custom cards, and a large scrollable feed. Each example includes setup code and a live callback log.

Start here

  1. Load the helper and its styles with uiLoader, then get the createTimeline factory.
  2. Provide a host element and items with stable unique IDs and ISO timestamps that include a timezone.
  3. Choose a small grouped timeline or a virtualized feed. Only virtualized feeds need a bounded host height.
  4. Connect callbacks to your application, and call destroy() when the view is removed.
Copyable minimal setup

Paths below assume a page in demos/. Adjust the import for your application. The loader loads the component CSS; no framework is required.

<div id="history"></div>
<script type="module">
import { uiLoader } from "../js/ui/ui.loader.js";
await uiLoader.load("ui.timeline");
const createTimeline = await uiLoader.get("ui.timeline");
const host = document.getElementById("history");
const items = [{
  id: "incident-42-received",
  timestamp: "2026-03-09T08:04:00+08:00",
  title: "Call Received",
  subtitle: "Operator Maya",
  description: "Initial intake completed.",
  status: "accepted",
  meta: ["Hotline", "Inbound"],
  actions: [{ id: "open", label: "Open incident" }],
}];
const timeline = createTimeline(host, items, {
  groupByDate: true,
  timeZone: "Asia/Manila",
  onActionClick(action, item) { console.log(action.id, item.id); },
});
// When your view is removed: timeline.destroy();
</script>

Troubleshooting checklist
  • No scrollable virtual feed: give the host a bounded height; check vertical orientation, enableVirtualization, and the visible item count against virtualThreshold.
  • State disappears after scrolling: keep state keyed by stable unique item ID outside the mount. Never rely on a retained offscreen DOM node.
  • Unexpected date groups: include offsets in input timestamps and choose an explicit timeZone. Missing or invalid timestamps belong to the undated group.
  • Jump did not land: inspect result.reason: not-loaded, filtered, cancelled, or destroyed. Load missing data in your app before retrying.
  • Expansion moves the viewport: change presentation inside the synchronous mutate callback, update the existing mount, and invalidate affected IDs. Do not rebuild the entire timeline for each click.
  • Older-page request fires only once: the end boundary is latched. Append new records on success; use resetReachEnd() for an explicit retry after failure.

Try these behaviors

  • Collapse All / Expand All: changes all loaded items, including offscreen ones. Click a header, or focus it and press Enter or Space, to override one message.
  • Jump to Event: try 120 for a loaded offscreen item or 999 for a missing item. This demo expands the target before focusing it. The helper does not fetch missing records.
  • Prepend Newer / Append Older: adds 8 newer or 12 older in-memory records. Scroll partway down before prepending to observe anchor preservation.
  • Retry End: resets the paging notification latch. Scroll near the end to see onReachEnd. This demo logs the request; it does not contact a server.
  • Date groups: scroll into March 8 to see the floating date change. It remains available even when the original heading is outside the rendered window.
  • Narrow layouts: at a feed width of 520px or less, sender, addressed, and preview stack in rows; the time stays top-right. The preview is one line with an ellipsis.
What belongs to the helper, and what belongs to your app?

The helper owns date labels, markers, measured row heights, viewport anchoring, and offscreen navigation. The sender/addressed fields, disclosure buttons, expansion state, follow-up action, and responsive message columns are this demo's custom renderer. There is no built-in collapsed item option.

Keep expansion state outside the mounted DOM: virtualized rows are removed and remounted while scrolling. Return an update() hook from mountItemContent, and call invalidateLayout(id, { mutate }) for presentation changes. Use contentKey only when replacing the nested component itself.

Height estimates, paging, and cleanup

Give the host a height, for example height: 480px; min-height: 0. Virtualization activates only for vertical feeds at or above virtualThreshold. The helper measures mounted rows; estimateItemHeight(item, { startsGroup }) predicts the complete offscreen unit, including date heading and spacing. Tune estimates for your own renderer and narrow layout.

In onReachEnd, let your application load the next page. Set isLoading: true with update while fetching, append the returned older records, then update hasMore and clear loading. Supply the full current item collection when calling update. On failure, clear loading and expose a retry button that calls resetReachEnd(). Avoid automatically retrying in a loop.

Return destroy() from custom mounts to release listeners, media, timers, and observers. Call the timeline's destroy() when leaving the view. Neither the helper nor this demo persists your messages.
