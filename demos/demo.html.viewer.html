HTML review documents

Static document previews with an isolated sandbox and explicitly approved images. Use the editor to try a side-by-side comparison or hostile content.

Host integration

const create = await uiLoader.get('ui.html.viewer');
const viewer = create({ content: html, resolveImage });
viewer.open(); // Canonical modal appears before resolving images.
// resolveImage(reference, {signal, alt}) returns an approved raster Blob.
// Do not fetch untrusted references directly.
viewer.update({ content: nextDocument });
await viewer.close();
viewer.destroy();

For Markdown use ui.markdown.viewer with images: true and the same resolver. Raw HTML stays escaped. Images are otherwise disabled.

Try and verify

  • The comparison uses two generated project images; no document URLs are fetched.
  • Reject images to see captions and alt text preserved.
  • The hostile example drops scripts, forms, CSS resources and active navigation.
  • Close while loading, reopen, resize, or use Fullscreen. Tab out of the document returns to Close.
  • The sandbox cannot forward Escape to its parent. Use Tab then Escape or the visible Close control.
