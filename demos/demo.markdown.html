Integration recipe

import { uiLoader } from "../js/ui/ui.loader.js";
const createMarkdownView = await uiLoader.get("ui.markdown");
const view = createMarkdownView(host, {
  markdown: message.body,
  profile: "compact",
  maxLines: 3,
  showMoreLabel: "Show more",
  showLessLabel: "Show less"
});

view.update({ markdown: updatedMessage.body });

Security and lifecycle checklist

  • Pass original Markdown as a string. Never pass rendered content through another HTML formatter.
  • Links permit absolute HTTP, HTTPS and mailto only. Relative links, credentials and dangerous schemes become plain labels.
  • Images, custom renderers, sanitizer overrides and executable HTML are unavailable.
  • Inputs above 256 KiB UTF-8 display a bounded plain-text preview. getState().reason explains fallback; getSource() retains the complete input.
  • Invalid options throw before updating the existing view. Parse or sanitizer failure produces safe text. Updates reset expansion.
  • Translate empty/fallback, Show more/less, code and table labels through options. Labels are text, never HTML.
  • For Trusted Types, allow the dompurify policy. See the reference for CSP configuration and failure behavior.

Use Tab and Enter/Space to expand a preview. Links and full code/table scroll regions remain keyboard reachable. Resize the page to check wrapping.
