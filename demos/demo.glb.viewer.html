GLB Viewer

Preview self-contained glTF 2.0 binary scenes locally. Drag to orbit, right-drag to pan, scroll/pinch to zoom. Keyboard and labeled controls offer the same actions. Use Wireframe to inspect mesh edges; toggle it off to restore the original materials without moving the camera.

Developer reference

const create = await uiLoader.get('ui.glb.viewer');
const viewer = create({title: 'Scene', context: projectId,
  load: ({signal, context}) => readAuthorizedFile(context, fileId, signal)
});
viewer.open(); // Shows immediately; renderer loads lazily.

Complete contract and format limits

The demo scene is synthetic and contains an embedded checker texture, floor and two props. No model data is uploaded. The rendering module is served from this site. Compressed geometry, external textures and animation controls are outside this first version.
