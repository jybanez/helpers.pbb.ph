ZIP archive viewer

Browse an archive locally. Only the selected file is decompressed, bounded and integrity checked. No archive is uploaded or unpacked to disk.

Try it

  1. Open the synthetic archive and select models/room.glb.
  2. Preview opens the canonical GLB viewer above the archive. Close it to return to your selection.
  3. Select readme.txt. Preview is disabled by this demo's filter; Download remains available.

Developer contract

const create = await uiLoader.get('ui.zip.viewer');
const viewer = create({
  load: ({signal, context}) => readAuthorizedZip(context, signal),
  canPreview: entry => /\.glb$/i.test(entry.name),
  onPreview: ({entry, blob, signal, context, restoreFocus}) => {
    // Route verified bytes to your canonical child viewer.
    // Cancel child on signal.abort; call restoreFocus on child close.
  }
});
viewer.open(); // Immediate loading modal

Limits: 64 MiB archive/entry, 2000 entries, 4 MiB metadata, 256 MiB total declared expansion. UTF-8/ASCII stored and deflated ZIP only. Encryption, ZIP64 and unsafe names are rejected.
