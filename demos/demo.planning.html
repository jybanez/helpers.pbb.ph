Build this composition

The reorder component owns milestone order, group membership, and item order. Each milestone header and deliverable row mounts independent text, select, and date editors. The column header is optional page content; accessible editor labels remain available when it is hidden.

  • Inline Text guide — required values, multiline notes, and custom validation.
  • Inline Select guide — searchable choices, disabled options, and stored IDs.
  • Inline Date guide — unset dates, range limits, and local date/time values.
  • Grouped Reorder guide — keyboard moves, locked items, event payloads, and persistence.

Try failure and recovery

Enable Fail next save before editing or moving an item. Field saves retain the draft on rejection; a failed reorder restores its previous order. Saves here use a local delay and never send a request. This composition waits for all edits to finish before starting an order mutation, then uses a non-rebuilding interaction lock until the simulated request finishes.

Integrate with your application

Return each editor’s destroy callback from renderItem so rebuilding the board disposes its controls. Persist field values independently only when your business rules permit it. Persist membership and both affected group orders atomically with server authorization and version checks. Reconcile uncertain network outcomes before offering another save.
