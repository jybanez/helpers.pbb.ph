# Two-point map ruler

Load `ui.map.ruler` with the Helper loader; its factory is `createMapRuler(resultHost, { map, maplibre, beforeActivate, onStateChange, onError })`. MapLibre 4.6.0 is an existing engine prerequisite, not included in the Helper bundle. One ruler may exist per map. The complete component owns transient GeoJSON layers, endpoint interaction, distance display, copy/reset/exit buttons and lifecycle. It never touches drawing features, save requests, GPS or persistence.

Place the result host at bottom center with clearance for other overlays. `getElement()` returns the component or null after destroy; `getSize()` returns its current visible width/height, zero when hidden/destroyed. Host placement belongs to the app. Use the complete `createMapControls` custom action immediately after Layers: icon `map.ruler`, label `Measure straight-line distance`, initial `pressed:false`. Synchronize `pressed:state.active` and `disabled:state.pending || state.destroyed` using `setActionState`. Its supported nullable `pressed` option updates `aria-pressed` without replacing the button or losing focus.

`activate(): Promise<boolean>` deduplicates pending calls. `beforeActivate({signal})` must return exactly true only after the app's existing dirty/draft editor exit confirmation has succeeded and all competing drawing/POI/search input is released. Keep editing, failed save, invalid draft, dismissal or changed context returns false. Never automatically discard or save. Suspend competing click handlers before returning true; use state callbacks to restore them on exit. The component cannot disable application handlers it does not own. The signal aborts on pending cancellation; the app must also guard its own confirmation context. Without a guard, activation assumes exclusive input ownership.

Call `deactivate()` when another workflow starts or context changes; it cancels pending activation, prevents late approval from activating, clears geometry/result, and restores the original double-click zoom state. It preserves navigation handlers. `reset()` clears the pair while keeping an active ruler ready. First click/tap anchors, pointer movement previews, second click/tap fixes, third ordinary click replaces the result with a new first point. Escape within the map/result and the Exit button deactivate. Drag/zoom/rotate/pitch gestures do not measure; a new pointer press re-arms clicks. MapLibre's native click threshold prevents drag clicks. Mobile is a two-tap flow; preview does not require hover.

`getState()` returns copied `start/end/preview` coordinates, `pending`, `active`, `destroyed`, `phase` (`inactive/ready/preview/complete`), `result` (`distanceMeters/text/fixed`), `copying`, and `copyStatus`. `onStateChange(snapshot)` fires synchronously after state commits, including pending activation, denied/successful activation, points/preview, reset, exit, clipboard outcomes and destruction. Callback updates should not re-enter state mutations. `update(options)` updates callbacks and cancels a pending guard; changing map or engine throws (destroy/recreate instead). `destroy()` is idempotent, removes owned DOM/listeners/layers, and invalidates pending work. Map removal destroys; style reload restores active transient layers.

Native `LngLat.distanceTo` measures the shortest spherical geographic separation. Display uses rounded m below 1000 m and two-decimal km otherwise. Same-point endpoints are valid zero. Nonfinite coordinates or latitude outside ±90° are ignored. Seam rendering unwraps the second longitude onto the shortest segment; the visible straight map segment is not a geodesic route or a terrain surface measurement.

Copy is enabled for a fixed result and runs only from the copy button's user gesture. It copies the displayed metric distance. Pending writes deduplicate. Success and unavailable/rejected clipboard failures have visible accessible feedback; the distance remains selectable for manual copy. Reset, exit, changed points and destruction invalidate stale feedback. An already-issued operating-system clipboard write cannot be aborted and may still complete after exit.

See `demos/demo.map.ruler.html` for source or `?bundle` parity, below-Layers activation, bottom-center result, guard denial, tilt, style reload and recreation. No tiles or external requests are required by this demo.

Rendering uses style availability, independent of pending raster/terrain tiles. It installs its source/layers before base sources finish, repairs missing owned resources after full or incremental style replacement through a guarded `styledata` recovery, and never rewrites intact resources merely because a style event fires. Initially unavailable styles defer installation until style availability; cancellation and teardown remain available. See [map-ruler-render-readiness.md](map-ruler-render-readiness.md) for the 312 failure and 313 correction.
